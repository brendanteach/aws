AWS Architecture for a Financial Web App

Build a production-grade financial app on AWS — frontend, backend, database, auth, async jobs, monitoring, and deployment. Taught by analogy to Azure.

Prerequisites Familiarity with web application concepts (frontend/backend/database). Azure cloud experience is useful — Azure analogies are used throughout. No prior AWS experience required.
