# Prior Azure Knowledge — Strong Foundation for AWS Transition

User has hands-on Azure experience covering the main cloud service categories: compute, storage, database, networking. No prior AWS experience.

**Evidence:** User self-reported.

**Implications:** Teach AWS by analogy to Azure — anchor each new service to its Azure equivalent. Skip "what is cloud?" fundamentals entirely. Focus lessons on *where AWS differs* from Azure, not on cloud basics. Financial web app goal means VPC, IAM, RDS, ECS/Lambda, S3+CloudFront are the critical path.
