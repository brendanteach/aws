# SageMaker AI Is the Machine Shop; Bedrock Is the Vending Machine

User asked for a lesson on SageMaker — what it is, how to use it with AI. Natural companion to [[0004-agentcore-rag-multiagent]] and the Bedrock lesson (14): the "build/host your own model" side of AWS AI, vs Bedrock's "consume an FM via API" side.

**Evidence:** Direct two-part request. Verified current state against AWS docs before writing (Jan 2026 cutoff): the Dec-2024 rebrand — original service is now **Amazon SageMaker AI** (the ML platform), and **Amazon SageMaker** is the broader unified data+analytics+AI umbrella (Unified Studio, Lakehouse, EMR/Glue/Redshift/Athena). HyperPod persistent self-healing clusters (vs ephemeral training jobs), and its July-2025 support for one-click open-weights FM deployment from JumpStart.

**Implications:** Delivered as Lesson 20 (bonus track, tag "Generative AI"). Azure anchor is Azure Machine Learning — near feature-for-feature. Core teaching: the "bring code, AWS runs infra" model; the fit→register→deploy→monitor loop; component map (Studio, JumpStart, training jobs, tuning, Pipelines, Model Registry, Feature Store, Model Monitor, Clarify, HyperPod). The key decision framing is **SageMaker AI vs Bedrock** (table): Bedrock when a catalogue model fits (serverless, per-token); SageMaker for custom/classical models, specific open-weight LLMs, full fine-tuning control, or VPC/data isolation. Two how-to tracks: (A) classical model for the finance app — XGBoost fraud scorer via `Estimator.fit/deploy` + `invoke_endpoint` from the API; (B) host/fine-tune an LLM via `JumpStartModel`/`JumpStartEstimator`. Inference options table (real-time / serverless / async / batch). Cost trap flagged hard: real-time endpoints bill per instance-hour 24/7 unlike Bedrock's per-token — use serverless inference, scale-in autoscaling, Managed Spot. Finance callouts: Model Registry approval + Model Cards (SR 11-7), Clarify for fair-lending bias + SHAP for ECOA/Reg B adverse-action reasons, VPC-only network isolation, Model Monitor drift as a model-risk event. Also noted the compose pattern: SageMaker endpoint as an AgentCore Gateway tool (Lesson 16). Still architecture-level. Natural next steps: SageMaker Pipelines end-to-end, HyperPod fine-tuning, or wiring an endpoint as an agent tool.
