# Teaching Notes

## User Profile
- Has Azure experience (Azure App Service, Azure Blob, Azure SQL, etc.)
- No prior AWS hands-on experience
- Goal: architectural understanding for real financial web app production deployment
- Learns best via Azure→AWS analogies

## Teaching Preferences
- Use Azure equivalents as anchors when introducing AWS concepts
- Finance context always: security, compliance, HA are always relevant
- Lessons should be immediately applicable to architecture decisions

## Pacing
- Start with the big picture (what services exist, how they map to Azure)
- Then drill into each layer: frontend → backend → database → networking → security
